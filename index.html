About CampusConnect

Open Academic Sharing Built for College Campuses

CampusConnect is a student-first study repository designed to eliminate scattered chat-group PDFs and lost lecture handouts. Every resource is tagged by Subject, Semester, and Category so students find exam-ready materials fast.

Role-Protected Moderation

Students upload and manage their own PDFs, while only authorized administrators can approve, reject, or remove inappropriate submissions.

Pure Web Standards + Firebase

Built with semantic HTML5, responsive CSS3, modular JavaScript, and powered by Firebase Authentication, Cloud Firestore, and Firebase Storage.

How to Connect Your Firebase Project

Follow these steps to connect Authentication, Firestore, and Storage to this website.

  1. Create a Firebase Project: Visit Firebase Console, click Create a project, and enter a project name such as campusconnect-app.
  2. Register a Web App & Copy Config: In Project Overview, click the Web icon (</>), register your app, and copy the firebaseConfig object. Paste it at the top of js/firebase-config.js.
  3. Enable Email/Password Authentication: Go to Build → Authentication → Sign-in method and enable Email/Password. In the Users tab, add eng25cs0761@dsu.edu.in with your chosen admin password.
  4. Enable Cloud Firestore & Rules: Go to Build → Firestore Database → Create database, then paste the contents of firestore.rules into the Rules tab and click Publish. Uploaded images and notes are saved directly as Base64 in Firestore—no Firebase Storage setup required.
